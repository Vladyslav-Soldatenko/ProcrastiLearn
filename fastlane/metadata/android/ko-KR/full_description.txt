휴대폰에는 Anki도, Duolingo도 깔려 있고, 언젠가 해야지 하는 마음도 있습니다. 그런데 막상 휴대폰을 들면 20분 뒤엔 어느새 틱톡을 보고 있고, 어쩌다 그렇게 됐는지도 모릅니다.

ProcrastiLearn은 바로 그 순간에 끼어듭니다. 또 다른 시간 낭비에 빠져들려는 찰나에 당신을 붙잡고, 먼저 단어 하나를 물어봅니다.

이렇게 무심코 앱을 여는 습관이 단어 학습으로 바뀝니다. 습관적으로 열게 되는 앱들 — 소셜 미디어, 브라우저, 게임 등 — 을 고르면, 그 앱을 실행할 때마다 전체 화면 플래시카드가 나타납니다. 번역을 확인하고 얼마나 잘 기억했는지 평가하면, 원래 열려던 앱이 바로 실행됩니다. 구독도, 광고도, 계정도 필요 없습니다.


사용 방법

앱 탭에서 차단할 앱을 선택하세요. 그 순간부터 해당 앱을 열 때마다 먼저 플래시카드가 표시됩니다. 답을 평가하면(다시/어려움/좋음/쉬움) FSRS 간격 반복 알고리즘이 다음 복습 시점을 자동으로 계산합니다. 일일 한도 설정으로 학습량이 과하지 않도록 조절할 수 있습니다.

차단된 앱 안에서 시간 가는 줄 모르고 머무는 편이라면, 선택적으로 반복 알림 기능을 사용해 보세요. 간격(예: 3분마다)을 설정하면 해당 앱에 머무는 동안 오버레이가 계속 다시 나타나, 오래 머무는 시간을 추가 복습 기회로 바꿔줍니다.


단어 학습

단어를 직접 추가하거나, 선택적으로 AI 번역 기능을 사용할 수 있습니다. 단어를 붙여넣고 생성을 누르면 OpenAI를 이용해 번역 초안을 만들어줍니다. AI 프롬프트는 자유롭게 수정할 수 있어 어조, 문맥, 목표 언어를 원하는 대로 조절할 수 있습니다.

기존에 사용하던 Anki 덱(.apkg 파일)을 가져와 이미 신뢰하는 단어 세트로 바로 시작할 수도 있습니다. 이후에는 틱톡이나 좋아하는 유튜버 영상을 보면서도 결국 그 단어들을 익히게 될 거라 확신할 수 있습니다.

기사, 채팅, 다른 앱 등 어디서든 새로운 단어를 발견하면, 그 단어를 선택하고 메뉴에서 "ProcrastiLearn에 추가"를 누르세요. 다른 앱으로 전환할 필요 없이 바로 추가됩니다.


언어 지원

AI 프롬프트는 설정에서 선택한 사용 언어와 학습 언어에 맞춰 자동으로 조정됩니다. 설명은 사용 언어로, 예문은 학습 중인 언어로 표시됩니다. 어떤 언어 조합이든 별도의 프롬프트 수정 없이 바로 작동합니다. GitHub 이슈나 이메일을 통한 사용자 요청을 바탕으로 언어 관련 기능은 앞으로도 계속 개선될 예정입니다.


개인정보 보호

단어, 차단 앱 목록, 복습 기록, 설정 등 모든 데이터는 오직 기기 안에만 저장됩니다. 분석 도구도, 충돌 보고 도구도, 광고 SDK도 전혀 없습니다. 외부로 나가는 유일한 네트워크 트래픽은 생성 버튼을 눌러 직접 요청하는 선택적 OpenAI API 호출뿐이며, 이때는 설정에서 직접 입력한 사용자 본인의 API 키를 사용합니다.


권한

접근성 서비스: 현재 어떤 앱이 화면 앞에 있는지 감지해 ProcrastiLearn이 오버레이를 표시할 시점을 판단하는 용도로만 사용됩니다. 화면 내용, 키 입력 등 다른 어떤 정보도 읽지 않습니다.

다른 앱 위에 표시: 차단된 앱 위에 플래시카드 오버레이를 그리기 위해 필요합니다.
