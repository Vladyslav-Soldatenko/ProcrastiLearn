มีทั้ง Anki และ Duolingo อยู่ในโทรศัพท์ และคุณก็ตั้งใจว่าจะกลับไปใช้มันสักวัน แต่พอหยิบโทรศัพท์ขึ้นมา ยี่สิบนาทีต่อมากลับอยู่ใน TikTok โดยไม่แน่ใจด้วยซ้ำว่าเข้ามาได้อย่างไร

ProcrastiLearn เข้ามาช่วยในจังหวะนั้นพอดี มันดึงคุณไว้ก่อนที่คุณจะจมหายไปกับสิ่งที่กินเวลาอีกอย่าง แล้วขอให้ทบทวนคำศัพท์เพียงหนึ่งคำก่อน

นั่นคือวิธีเปลี่ยนการเปิดแอปแบบไม่รู้ตัวให้กลายเป็นการฝึกคำศัพท์ เลือกแอปที่คุณมักเปิดจนเป็นนิสัย — โซเชียลมีเดีย เบราว์เซอร์ หรือเกม — แล้วทุกครั้งที่เปิดแอปนั้น หน้าต่างบัตรคำแบบเต็มหน้าจอจะปรากฏขึ้น ดูคำแปล ให้คะแนนว่าคุณจำได้ดีแค่ไหน แล้วแอปที่คุณต้องการจะเปิดทันที ไม่มีค่าสมาชิก ไม่มีโฆษณา และไม่ต้องมีบัญชี


วิธีการทำงาน

เลือกแอปที่ต้องการตั้งด่านไว้ในแท็บ แอป หลังจากนั้น ทุกครั้งที่เปิดแอปเหล่านั้น คุณจะเห็นบัตรคำก่อน ให้คะแนนคำตอบของคุณ (อีกครั้ง / ยาก / ดี / ง่าย) แล้วอัลกอริทึมการทบทวนแบบเว้นระยะ FSRS จะกำหนดเวลาทบทวนครั้งถัดไปโดยอัตโนมัติ ขีดจำกัดรายวันช่วยไม่ให้คุณต้องรับภาระมากเกินไป

หากคุณมักลืมเวลาเมื่ออยู่ในแอปที่ตั้งด่านไว้ ระบบเตือนซ้ำทางเลือกนี้ช่วยได้: กำหนดช่วงเวลา (เช่น ทุก 3 นาที) แล้วหน้าต่างทับจะปรากฏขึ้นอีกตราบใดที่คุณยังอยู่ในแอปนั้น เปลี่ยนช่วงเวลาที่อยู่เพลินให้เป็นการทบทวนเพิ่ม


คำศัพท์

เพิ่มคำศัพท์ด้วยตัวเอง หรือใช้ฟีเจอร์คำแปลจาก AI ที่เป็นทางเลือก: วางคำศัพท์ แตะ สร้าง แล้วแอปจะร่างคำแปลด้วย OpenAI คุณแก้ไขพรอมต์ AI ได้ทั้งหมด เพื่อควบคุมน้ำเสียง บริบท หรือภาษาปลายทาง

คุณยังนำเข้าชุดบัตรคำ Anki ที่มีอยู่ (.apkg) เพื่อเริ่มต้นด้วยคำศัพท์ที่คุณเชื่อถืออยู่แล้วได้ทันที หลังจากนั้น คุณจึงมั่นใจได้ว่าสุดท้ายจะได้เรียนรู้มัน ไม่ว่าจะกำลังดู TikTok หรือ YouTuber คนโปรดของคุณ

เจอคำศัพท์จากที่อื่น — บทความ แชต หรือแอปอื่น? เลือกคำศัพท์นั้นแล้วแตะ “เพิ่มใน ProcrastiLearn” จากเมนูเพื่อเพิ่มทันที โดยไม่ต้องสลับแอปก่อน


การรองรับภาษา

พรอมต์ AI จะปรับตามภาษาแม่และภาษาที่คุณกำลังเรียนซึ่งเลือกไว้ใน การตั้งค่า โดยอัตโนมัติ: คำอธิบายจะแสดงเป็นภาษาแม่ และตัวอย่างจะแสดงเป็นภาษาที่คุณกำลังเรียน ใช้คู่ภาษาใดก็ได้ทันที โดยไม่ต้องแก้ไขพรอมต์เอง การปรับปรุงด้านภาษาจะทยอยมาเพิ่มเติม โดยเฉพาะจากคำขอของผู้ใช้ใน GitHub issues หรือทางอีเมล


ความเป็นส่วนตัว

ข้อมูลทั้งหมด — คำศัพท์ รายการแอปที่บล็อก ประวัติการทบทวน และการตั้งค่า — เก็บอยู่ในอุปกรณ์ของคุณทั้งหมด ไม่มีการวิเคราะห์ข้อมูล ไม่มีตัวรายงานข้อขัดข้อง และไม่มี SDK โฆษณา การรับส่งข้อมูลออกนอกอุปกรณ์มีเพียงการเรียก OpenAI API แบบทางเลือกที่คุณเริ่มเองด้วยการแตะ สร้าง โดยใช้คีย์ API ของคุณเองที่กรอกไว้ใน การตั้งค่า


สิทธิ์

Accessibility Service: ใช้เพียงเพื่อตรวจจับว่าแอปใดกำลังอยู่ด้านหน้า เพื่อให้ ProcrastiLearn รู้ว่าเมื่อใดควรแสดงหน้าต่างทับ บริการนี้ไม่อ่านเนื้อหาบนหน้าจอ การกดแป้นพิมพ์ หรือข้อมูลนำเข้าอื่นใด

แสดงทับแอปอื่น: จำเป็นสำหรับวาดหน้าต่างบัตรคำทับแอปที่ตั้งด่านไว้
